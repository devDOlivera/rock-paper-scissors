# rock-paper-scissors
A JavaScript implementation of the classic Rock, Paper, Scissors game.

The game runs in the browser without a graphical user interface (GUI). Players compete against the computer, and the results are displayed in the browser's developer console.

## Features

- Single-player gameplay against the computer.

- Randomly generated computer choices.

- Five-round matches.

- Score tracking throughout the game.

- Round-by-round results.

- Final winner announcement with the respective scores.

- No external dependencies.

## Technologies

- **JavaScript:** Game logic and functionality.

- **HTML:** Entry point for running JavaScript in the browser.

## Getting Started

1. Clone or download the repository.

2. Open the index.html file in your web browser.

3. Open the developer tools by pressing F12.

4. Navigate to the Console tab.

5. Follow the game instructions.

## Game Rules

- Rock beats scissors.

- Scissors beats paper.

- Paper beats rock.

- Identical choices result in a draw.

Each match consists of five rounds. The scores are tracked throughout the match, and the player with the highest score at the end wins. If both players have the same score, the match ends in a draw.
